# System Analizy Danych Sprzedażowych (CSV)

Aplikacja konsolowa w języku Python 3.13 realizująca strumieniowy potok przetwarzania danych sprzedażowych (ETL), walidację rekordów za pomocą wyrażeń regularnych, wieloprocesową agregację statystyk oraz wielowątkowy eksport raportów.

## Wymagania i instalacja

- **Python:** 3.12+ (testowano na CPython 3.13.5)
- **Zależności zewnętrzne:** `matplotlib`, `pytest`

Instalacja bibliotek:

pip install -r requirements.txt
